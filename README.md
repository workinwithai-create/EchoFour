# EchoFour

Four-bar live echo desk for bedroom producers and AI-music finishers.

Generators loop the motif or dump full density into the next section.
Session players write four live bars of delayed answer — nylon echo, violin tail, trumpet recall — so the section has space and the track can finish.

Live samples only (FluidR3 piano, upright, nylon, trumpet, violin, acoustic kit) loaded from the PreEight sample bank pinned to commit SHA.
No oscillators. Audio never leaves the tab.

Yesterday's ship was VarFour (variation so the repeat is not a photocopy).
EchoFour is the delayed answer that creates air before the next section.

Distinct from TagFour (last-line end tag), LiftTwo (pre-hook lift), PreEight (musical climb), AfterHook, EndEight, LastHook, AnswerFour (call and response), GhostFour (ghost notes), AirFour, ThinFour.

## Form
1–4 motif · 5–8 echo

## Play
* A · Motif loop
* B · Full form
* 8 · Echo only
